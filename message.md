# 🚀 Big News: TrustFactor is now Open Source!

We are thrilled to announce that **TrustFactor**, the community-driven reputation and scoring bot, is now officially open source! 

This move allows us to build a more transparent, secure, and feature-rich tool together with the community. The full codebase is now available for you to explore, fork, and contribute to.

## 🌟 What's New in This Release?

We've been hard at work over the last few days to polish the experience. Here is what has landed:

### 🎨 Stunning New Visuals
We have completely overhauled how data is presented. Say goodbye to plain text embed tables!
- **Rich Image Generation:** The `/score`, `/leaderboard`, `/stats`, and `/award` commands now generate beautiful, custom-rendered images dynamically.
- **HTML Renderer:** Under the hood, we've implemented a robust HTML-to-Image renderer to make your stats look cleaner and more professional.

### ⚡ Performance & Stability
- **Faster Responses:** We've optimized command handling (especially for `/score`) to prevent timeouts, ensuring you get your data when you need it.
- **Smart Caching:** Server configurations are now cached and invalidated intelligently, reducing database load and speeding up interactions.
- **Browser Management:** Enhanced browser instance management for image generation means smoother performance during peak usage.

### 🗳️ Enhanced Voting & Interaction
- **Better Feedback:** We've improved the feedback loop when starting votes and reacting to messages.
- **Refined Logic:** The voting system has been tweaked to handle reactions and score updates more reliably.
